# The API

`app/api/docs/`: list/create (import) and per-document GET/PUT/POST(beacon)/DELETE. `POST /api/docs/<id>/codex/<eid>/move` `{ to }` moves an entry to another book's Codex or the Global Codex (`_global`), answering `{ id }`, its id there. Saves carry `baseVersion` (sha1 of content); a stale save gets 409 with the current doc. They also carry `pasted`, the words pasted since the last save, for the [writing stats](stats.md) (`/api/stats`). Every handler (all of `app/api` but `auth` and `construct/mcp`) is wrapped in `route()` (`lib/route.ts`): the session re-check, params awaited, and `id`/`eid`/`vid` params validated (404) before it runs (with `route(fn, { global: true })`, `id` may also be `_global`, the [Global Codex](library.md#the-global-codex): the Codex, entry, move, spot and Construct routes take it, every other route answers it 404); it answers with the helpers there (`notFound`, `badRequest`, `fail`, `noContent`, `noStore`) and reads bodies with `readJson`.
