# Imports into the Codex

## Critique Circle crits

Critique Circle crits (`lib/critiquecircle.ts`): a saved story page (`.html`) imported into the Codex is POSTed as `{ html }` to `/api/docs/<id>/codex`; the server turns it into an entry `# Crits: Part N of M`, each story paragraph as a blockquote followed by `**Critter**: …`, opening/closing comments around them. Non-CC pages get 422. `htmlparser2` does the parsing; the module imports nothing from pen so tests load it with plain Node.

## Handwritten notes

Handwritten notes (`lib/transcribe.ts`): pictures imported into the Codex (picker, which takes `image/*` so phones offer the camera, or drop) are shrunk in the browser to a ≤2000px JPEG (`prepareNote` in `lib/cover.ts`) and POSTed together, sorted by name, as `{ images: [base64…] }` to `/api/docs/<id>/codex`: the pages of one note, one entry. The server sniffs each (JPEG/PNG/WebP/GIF, ≤5 MB, ≤10 pages), answers `202 { job }` and the browser goes to the import's page, `/d/<id>/import/<job>` (`components/ImportNote.tsx`), while the server asks the transcription model once (`askOnce`, see Construct) with the pages and a prompt that asks for a faithful transcription, best guesses over gaps (guessed words marked `word[?]`, `[illegible]` only as a last resort), and the Codex titles as spelling hints; the reply becomes the entry (`entryFromReply`). Construct's chats aren't involved. Each import is a job in the server's memory (`lib/imports.ts`, on `globalThis`; the photos never touch the disk, a restart ends it, finished ones are forgotten after an hour), so the entry is still made if the page is closed. The page shows the photos (`GET /api/docs/<id>/imports/<job>/<n>`) and follows `GET /api/docs/<id>/imports/<job>`, JSON lines: a snapshot (`state`, text so far), then the answer (`text`) and a reasoning model's thinking before it (`thought`, `onThought` in `runOnce`, folded away once the answer starts) as they come, ending in `{ t: "entry", id }` (a link to it, nothing opens on its own) or `{ t: "error" }`. Stop and Dismiss are `DELETE` on the job. The Codex list shows running and failed jobs (`GET /api/docs/<id>/imports`) above the entries, linking to their page, and looks again every 3 s while one runs. A page takes ~10 s on Claude, ~25 s on a local model. Tests run one-off runs against a stub agent (`tests/fixtures/stub-acp-agent.mjs`).

## Into the Global Codex

Both work in the [Global Codex](library.md#the-global-codex) too (`/api/docs/_global/codex`, `/api/docs/_global/imports`). A note's prompt there names no book (`transcribePrompt` with `book: null`) and takes its names from the Global Codex's entries; its page is `/d/_global/import/<job>` (`components/ImportNote.tsx` leads back to `/codex`).
