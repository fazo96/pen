# Grammar check

Grammar check (`lib/grammar.ts`): Harper (`harper.js`, WASM) runs on the server only. The plugin checks changed blocks after a pause, cursor first (50 per request), and draws flags as decorations; `lib/grammarClient.ts` is the page's side (settings, flags cached by block text, `POST /api/grammar/check` for the rest; when that fails, `unreachable` and the pane says checking is paused until the next edit). `lib/grammarServer.ts` answers it and Construct's `grammar_check` alike: unfiltered flags (callers filter with `visibleFlags`) from `lib/grammarCache.ts`, a file per settings signature (Harper's version, dialect, rules, words; dictionary words change Harper's other flags and hashes, so they can't just be filtered) in `cache/grammar/<sig>.jsonl`, a line per paragraph `[sha1 of text, flags]`, appended, least recently used dropped past 50k, the newest 3 other signatures' files kept; else from Harper in a worker thread (`lib/harperWorker.ts`, plain JS run with `eval`, loading `harper.js` from node_modules; `next.config.ts` adds it to the standalone trace of both routes), because loaded it takes ~450 MB that Node never returns while the process lives. The worker ends after 5 idle minutes (`PEN_GRAMMAR_IDLE_MS` overrides). Batches of 50 go through one queue, so the editor isn't stuck behind a whole-book check. A first full check of a 20k-word book takes ~11 s; opening it again (any device, after a restart too) ~2 s without loading Harper. `lib/grammarText.ts` feeds it each textblock's text without comments or code, keeping document positions. Clicking a flag opens `components/GrammarPopover.tsx` (fixes, add to dictionary, ignore, turn off rule). The drawer's Grammar tab (`components/GrammarPane.tsx`) lists every flag by chapter, repeated unknown words first; it redraws only once typing pauses and renders 150 entries at a time, since a long book can have thousands. On/off is per device (localStorage `pen:grammar`), and turns the browser's spellcheck off while on. Dialect, dictionary, rule switches and ignored flags are library-wide in `PEN_DIR/.pen-grammar.json` (`lib/grammarConfig.ts`, `PATCH /api/grammar`, managed in `/settings`); `PEN_RULES` turns off Harper rules that are noise in fiction. Dictionary matching ignores case and a possessive ’s.
